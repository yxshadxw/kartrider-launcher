# KartRider Launcher and Korean resource patch

This fork contains the upstream launcher source and a separate Korean resource patch package.

## Korean resource patch

See [korean-translation/README.md](korean-translation/README.md) for instructions. The package translates supported in-game strings, adds Korean font resources, and replaces 312 image assets with existing Korean variants. It works on a user's own compatible game installation and does not redistribute the game client or RHO archives.

The patch does not modify `Launcher.exe`. Some Chinese-only images remain untranslated, and in-game runtime rendering has not been confirmed.

## Upstream

The launcher source remains from [MokeyBanana/kartrider-launcher](https://github.com/MokeyBanana/kartrider-launcher).
